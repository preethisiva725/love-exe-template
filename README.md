## 💌 What is LOVE.EXE?

LOVE.EXE is a fun interactive love website made for surprising someone special.

It includes:

- 💻 LOVE.EXE loading screen
- 🔐 Interactive fingerprint security screen
- 💗 "Your Person Detected" screen
- 💌 Romantic heart message
- 📂 Secret love files
- 🎮 "Catch Me If U Can" mini-game
- 📸 Memory scrapbook
- 🎵 Background music
- ❤️ Final love letter
- 📱 Mobile-friendly design

Everything is made using **HTML, CSS and JavaScript**.

## 🛠️ How To Customize

You don't need advanced coding knowledge!

### 1. Change the names

Open:

`index.html`

Search for:

`YOUR PERSON`

Replace it with your person's name.

You can also change any other text you want.

---

### 2. Change the romantic messages 💌

Open:

`index.html`

Look for the heart/confession section and replace the messages with your own.

---

### 3. Change the secret messages 🔐

Open:

`script.js`

Find the secret messages and replace them with your own personal messages.

---
